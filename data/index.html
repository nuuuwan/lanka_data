Lanka Data · Data directory · Upstream datasets · API guide

Find Sri Lankan census and election data

Lanka Data brings census and election data into one query tool. This directory and the snapshot tables work without JavaScript, authentication or an API key.

How to answer a data question

  1. Identify the subject (people, households or votes), year, geography and breakdown requested. Check these against a snapshot below.
  2. Open its readable table or JSON link and inspect the actual observations. Filter to the requested coordinates. Cite the table or JSON URL and its official provenance.
  3. If no snapshot fits, search the complete upstream dataset directory for the topic and dimension combination, then fetch the linked source file. Verify coverage in the file before answering.
  4. If the data or a required browsing capability is unavailable, say what could not be retrieved. Do not infer missing values or substitute another year or geography.

Sources are the Department of Census and Statistics of Sri Lanka and the Elections Commission of Sri Lanka, accessed through the public repositories used by the app. Availability varies by topic, year and geographic level.
